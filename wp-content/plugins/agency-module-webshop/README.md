# Agency Module: Webshop 1.12

Webshop skeleton module for future commerce features.

## Developer structure

Implement new commerce features in the shared feature-plugin layout:

- `bootstrap/`
- `includes/services/`
- `includes/repositories/`
- `includes/migrations/`
- `includes/admin/`
- `includes/frontend/`
- `includes/rest/`
- `templates/frontend/`
- `templates/admin/`
- `assets/css/`
- `assets/js/`

The current skeleton intentionally avoids a full commerce implementation; do not introduce order/payment behavior without an explicit feature ticket.
